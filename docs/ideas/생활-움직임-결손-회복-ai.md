# 생활 움직임 결손 회복 AI 스마트홈 서비스

> **장시간 집에 머무는 사용자의 생활 맥락을 이해하고, 그날 사라진 움직임을 발견하여 실제 행동과 보상까지 연결하는 AI 스마트홈 서비스**

---

# 1️⃣ 프로젝트 한 문장 정의

> 우리 프로젝트는 **집에 오래 머무는 사용자**가 장시간 같은 자세와 공간에 머물며 겪는 **생활 움직임의 공백**을 해결하기 위해,  
> **위치·자세·체류시간·식사·실내외 활동·이전 반응 데이터**를 바탕으로 그날 부족한 움직임과 개입 시점을 판단하고,  
> **맞춤 행동 제안·수행 확인·회복도 분석·웰니스 보상**을 제공하는 AI 스마트홈 서비스이다.

### 핵심 표현

> **기존 서비스가 “얼마나 운동했는가”를 본다면, 우리는 “집에서 어떤 움직임이 사라졌는가”를 본다.**

### 프로젝트 철학

> 사용자를 억지로 운동시키는 집이 아니라,  
> 사용자의 생활을 이해하고 사라진 움직임을 자연스럽게 돌려주는 집.

---

# 2️⃣ 프로젝트 배경

재택근무자, 프리랜서, 취업 준비생, 수험생, 고령자처럼 집에 오래 머무는 사람은 하루 동안 이동해야 할 이유가 적다. 출퇴근, 계단 이용, 식당 이동, 회의실 이동처럼 외부 생활에서 자연스럽게 발생하던 움직임이 집에서는 사라진다.

이들은 운동을 전혀 하지 않는 사람만을 의미하지 않는다. 하루에 30분 운동하더라도 나머지 시간 동안 책상이나 소파에 장시간 앉아 있을 수 있다. 따라서 단순한 운동량뿐 아니라 다음과 같은 생활 패턴을 함께 살펴볼 필요가 있다.

- 같은 자세가 너무 오래 지속되는가?
- 식사 후 거의 움직이지 않는가?
- 하루 동안 사용하는 공간이 지나치게 한정되어 있는가?
- 자세를 전환하거나 가볍게 움직이는 횟수가 부족한가?
- 낮 동안 실외 활동과 자연광 노출이 거의 없는가?
- 알림을 받아도 회의·공부·휴식 상황 때문에 계속 무시하는가?

한국 성인의 하루 평균 좌식 시간은 2023년 기준 약 9시간으로 보고되었으며, 2018년의 8.3시간보다 증가했다. 세계보건기구는 모든 연령대에서 좌식 시간을 줄이고, 이를 가벼운 강도의 신체활동으로 대체하는 것에도 건강상 이점이 있다고 권고한다.

- [WHO 신체활동 및 좌식 행동 가이드라인](https://www.who.int/publications/i/item/9789240015128)
- [WHO 신체활동 팩트시트](https://www.who.int/news-room/fact-sheets/detail/physical-activity)
- [국내 성인 좌식 시간 관련 보도](https://www.hani.co.kr/arti/society/health/1184275.html)
- [질병관리청 국가건강정보포털 – 신체활동](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6251)

# 3️⃣ 핵심 페인포인트

## 문제 1. 집에서는 자연스럽게 발생하던 움직임이 사라진다

외부 생활에서는 출퇴근, 대중교통, 식당 이동, 사람과의 만남을 통해 의식하지 않아도 움직인다. 하지만 집에서는 책상·침대·소파 사이의 짧은 이동만 반복하기 쉽다.

이 문제는 단순한 “운동 의지 부족”이 아니라 **생활 구조 자체에서 움직일 이유가 사라지는 문제**에 가깝다.

## 문제 2. 기존 서비스는 누적 운동량을 중심으로 평가한다

스마트워치와 헬스 앱은 걸음 수, 소모 칼로리, 운동 시간, 심박수 등을 잘 측정한다. 그러나 사용자가 집 안에서 어떤 자세로, 어느 공간에, 얼마나 오래 머물렀는지까지 충분히 해석하지는 못한다.

예를 들어 다음 두 사람은 하루 걸음 수가 같더라도 생활 패턴이 다르다.

```text
A 사용자
- 오전 운동 30분
- 이후 책상에서 5시간 연속 앉아 있음

B 사용자
- 별도의 운동 없음
- 집안일과 짧은 이동으로 하루 동안 움직임이 분산됨
```

기존 지표만으로는 두 사용자의 **연속 좌식, 자세 다양성, 식후 움직임, 공간 이동** 차이가 충분히 드러나지 않는다.

## 문제 3. 고정된 알림은 상황을 이해하지 못한다

“1시간마다 일어나세요”와 같은 알림은 구현하기 쉽지만 다음 문제가 있다.

- 중요한 회의 중에도 알림이 온다.
- 이미 집안일을 하고 있어도 알림이 온다.
- 사용자가 피곤하거나 아픈 날에도 같은 강도를 요구한다.
- 어떤 행동을 해야 하는지 구체적이지 않다.
- 반복적으로 무시하면 알림 자체를 꺼버리게 된다.

문제는 알림이 부족한 것이 아니라 **사용자가 실제로 움직일 수 있는 시점과 방식이 고려되지 않는 것**이다.

## 문제 4. 제안이 실제 행동으로 이어졌는지 확인하기 어렵다

기존 알림은 메시지를 전달한 뒤 역할이 끝난다. 사용자가 실제로 일어났는지, 산책했는지, 스트레칭했는지 확인하지 못한다. 따라서 어떤 제안이 효과적이었는지 학습하기도 어렵다.

## 문제 5. 꾸준히 실천할 동기가 부족하다

건강을 위한 행동은 효과가 즉시 눈에 보이지 않는다. 단순한 칭찬이나 조명 변화만으로는 장기적인 실천을 만들기 어렵다. 사용자는 다음을 확인할 필요가 있다.

- 오늘 어떤 움직임이 부족했는가?
- 그중 얼마나 회복했는가?
- 지난주보다 실제로 좋아졌는가?
- 꾸준히 실천했을 때 무엇을 얻을 수 있는가?

# 4️⃣ 타깃 사용자

## 1차 타깃

### 집에 장시간 체류하는 청년층

- 재택근무자
- 프리랜서
- 취업 준비생
- 공무원·자격증 수험생
- 온라인 강의를 오래 듣는 대학생
- 방학 중 집에서 대부분의 시간을 보내는 사람

### 타깃을 이렇게 설정하는 이유

- 장시간 좌식과 제한된 공간 사용 문제가 명확하다.
- 스마트폰과 앱 사용에 익숙하다.
- 자세·체류·알림 반응 데이터를 수집하기 비교적 쉽다.
- 한 학기 안에 대학생을 대상으로 사용자 실험을 진행할 수 있다.

## 2차 확장 타깃

- 은퇴 후 집에 머무는 시간이 긴 중장년층
- 거동은 가능하지만 외부 활동이 적은 고령자
- 육아로 외출이 어려운 보호자
- 일시적으로 외출이 제한된 사용자

> 고령자와 환자까지 초기 타깃으로 포함하면 의료적 안전성과 정확성 요구가 크게 높아진다.  
> 따라서 MVP에서는 건강한 성인, 특히 대학생과 청년층을 중심으로 검증하는 것이 현실적이다.

# 5️⃣ 만들고자 하는 생활 가치

## 핵심 가치

> **운동을 별도의 과제로 만들지 않고, 사라진 움직임을 일상 속에 다시 배치한다.**

## 세부 가치

- 장시간 이어지는 좌식·누운 상태를 자연스럽게 중단한다.
- 자신의 생활에서 부족한 움직임을 구체적으로 이해하게 한다.
- 상황에 맞는 부담 없는 행동을 제안한다.
- 단순 알림을 실제 행동으로 연결한다.
- 생활 변화의 결과를 수치와 리포트로 확인하게 한다.
- 꾸준한 행동을 실질적인 웰니스 혜택으로 연결한다.
- 착용형 기기를 항상 차고 있지 않아도 집이 생활 맥락을 이해하게 한다.

# 6️⃣ ‘생활 움직임 결손’의 정의

이 프로젝트에서 가장 중요한 개념은 **운동 부족**이 아니라 **생활 움직임 결손**이다.

## ① 자세 전환 결손

앉기, 서기, 눕기 등의 자세 변화가 지나치게 적은 상태.

### 예시

- 책상 앞에서 세 시간 동안 거의 움직이지 않음
- 소파에 비스듬히 누운 자세를 오래 유지함
- 하루 대부분을 앉거나 누워서 보냄

## ② 연속 좌식 결손

하루 전체 활동량과 별개로, 움직임 없이 앉아 있는 구간이 길게 이어지는 상태.

### 핵심 지표

- 최장 연속 좌식 시간
- 일정 시간 이상 이어진 좌식 구간 수
- 좌식 구간 사이의 활동 중단 횟수

## ③ 움직임 종류 결손

특정 움직임만 반복하고 다른 형태의 움직임이 거의 없는 상태.

### 예시

- 걸음 수는 충분하지만 상체를 거의 움직이지 않음
- 집안에서는 짧은 이동만 하고 별도의 스트레칭이 없음
- 운동은 했지만 나머지 시간 동안 자세가 고정됨

## ④ 생활 시점 결손

움직임이 필요한 생활 시점에 활동이 발생하지 않는 상태.

### 예시

- 식사 직후 바로 눕거나 장시간 앉음
- 아침부터 오후까지 한 번도 자리에서 일어나지 않음
- 취침 직전까지 같은 업무 자세를 유지함

## ⑤ 공간 이동 결손

하루 동안 사용하는 공간과 이동 범위가 지나치게 제한된 상태.

### 예시

- 침대와 책상만 반복해서 사용
- 하루 대부분을 하나의 방이나 한 자리에서 보냄
- 실외 이동이 전혀 없음

## ⑥ 실외 활동 결손

날씨가 괜찮고 일정상 여유가 있음에도 하루 동안 외부 활동이 거의 없는 상태.

> 햇빛 노출이나 비타민 D 부족을 의료적으로 진단하지 않는다.  
> 실외 활동이 거의 없다는 생활 사실을 바탕으로 짧은 산책을 제안하는 수준으로 제한한다.

# 7️⃣ AI의 핵심 역할

이 프로젝트에서 AI는 운동 영상을 생성하거나 일반적인 건강 조언을 하는 역할이 아니다.

## 핵심 역할 1. 결손 판단

다양한 데이터를 종합하여 오늘 사용자에게 어떤 움직임이 부족한지 판단한다.

```text
책상 체류 110분
+
앉은 자세 지속
+
점심 식사 후 공간 이동 없음
+
오늘 외부 활동 0분

↓

연속 좌식 + 식후 움직임 + 실외 활동 결손
```

## 핵심 역할 2. 개입 가능 시점 판단

움직임이 필요하더라도 사용자가 움직일 수 없는 상황이면 제안하지 않는다.

### 고려할 정보

- 온라인 회의 여부
- 키보드·마우스 집중 사용
- 일정과 마감 시간
- 수면·피로 관련 사용자 입력
- 현재 가전 사용 상황
- 최근 알림을 거절한 횟수
- 이전에 제안을 잘 수락했던 시간

## 핵심 역할 3. 적절한 행동 강도 선택

모든 결손을 운동으로 해결하지 않는다.

| 사용자 상태 | 가능한 제안 |
|---|---|
| 업무 집중 중 | 자리에서 1분 자세 전환 |
| 식사 직후 | 설거지 또는 가벼운 집안 정리 |
| 두 시간 이상 좌식 | 5분 걷기 |
| 실외 활동 없음 | 10~20분 산책 |
| 피로도가 높은 날 | 가벼운 스트레칭 |
| 이미 운동한 날 | 운동 추가 대신 좌식 중단 |

## 핵심 역할 4. 행동으로 이어지는 제안 방식 학습

AI는 어떤 문구, 시간, 행동, 보상이 사용자에게 효과적이었는지 학습한다.

```text
오전 산책 제안 → 반복 거절
점심 후 설거지 제안 → 수행률 높음
오후 스트레칭 + 포인트 → 수행률 보통
오후 짧은 걷기 + 웰니스 리워드 → 수행률 높음

↓

다음 주에는 점심 후 생활 행동과 오후의 짧은 걷기를 우선 제안
```

## 핵심 역할 5. 결과 설명

생성형 AI는 센서 원시 데이터를 직접 판단하는 핵심 모델보다, 다음 역할에 적합하다.

- 사용자가 이해하기 쉬운 제안 문장 생성
- 이번 제안을 하는 이유 설명
- 일간·주간 움직임 회복 리포트 작성
- 사용자의 음성·텍스트 피드백 요약
- 다음 주 목표를 자연어로 안내

> 핵심 판단 모델과 생성형 AI의 역할을 분리해야 한다.  
> 생성형 AI가 임의로 건강 상태를 진단하거나 운동 처방을 만들게 해서는 안 된다.

# 8️⃣ 필요한 Context와 데이터

| Context | 데이터 예시 | 활용 목적 |
|---|---|---|
| 위치 | 책상, 소파, 침대, 주방, 현관 | 공간별 체류 및 이동 파악 |
| 자세 | 앉기, 서기, 눕기, 이동 | 자세 전환과 연속 정적 상태 분석 |
| 시간 | 시각, 요일, 체류 지속시간 | 생활 리듬과 결손 구간 판단 |
| 행동 | 업무, 식사, 휴식, 집안일 | 제안 가능성과 행동 종류 선택 |
| 실내 환경 | 온도, 습도, 조도, 소음 | 활동하기 어려운 환경 판단 |
| 외부 환경 | 날씨, 미세먼지, 일몰 | 실내 활동과 산책 중 선택 |

| 가전 로그 | TV, 조명, PC, 주방가전 사용 | 생활 상황 추정 |
| 반응 이력 | 수락, 거절, 미응답, 수행 | 개인화 모델 학습 |
| 자기 보고 | 피로도, 통증, 컨디션 | 센서만으로 알 수 없는 상태 보완 |

# 9️⃣ 핵심 기능

## 기능 1. 생활 움직임 결손 분석

하루 데이터를 바탕으로 다음 항목의 결손 정도를 계산한다.

```text
자세 전환       90%
공간 이동       70%
식후 움직임     80%
실외 활동       30%
연속 좌식 관리  65%
```

단순 점수만 보여주지 않고 부족한 이유도 설명한다.

> 오늘은 총 활동량보다 오후 1시부터 3시까지 이어진 112분의 연속 좌식이 가장 큰 움직임 결손입니다.

## 기능 2. 상황 기반 행동 제안

AI가 현재 상태와 사용자의 선호를 바탕으로 실현 가능한 행동을 제안한다.

사용자가 제안이 마음에 들지 않으면 **비슷한 시간과 활동 강도를 가진 다른 움직임**을 즉시 선택할 수 있다. 예를 들어 5분 걷기 대신 5분 방 정리나 가벼운 스트레칭을 제시하며, 선택 결과는 이후 개인화에 반영한다.

### 제안 예시

- 물을 마시러 주방까지 다녀오기
- 좋아하는 음악 한 곡 동안 방 안 걷기
- 설거지나 빨래 정리하기
- 3분 상체 스트레칭
- 분리수거 다녀오기
- 날씨가 좋을 때 15분 산책하기
- 오래 누워 있었다면 앉거나 서서 활동하기

## 기능 3. 수행 자동 확인

제안 이후 위치·자세·스마트폰·가전 데이터의 변화를 확인해 실제 수행 여부를 판단한다.

### 예시

```text
제안: 5분 동안 집 안을 걸어보세요.

확인 데이터:
- 책상 영역 이탈
- 서 있는 자세로 전환
- 두 개 이상의 공간 이동
- 4분 30초 이상 활동

결과:
- 수행 완료
- 움직임 결손 회복도 반영
- 회복 크레딧 지급
```

정확한 의료 운동 동작을 판정하는 것이 아니라, **제안한 생활 행동이 실제로 발생했는지** 확인하는 수준을 목표로 한다.

## 기능 4. 오늘의 움직임 결손 회복도

사용자가 그날 부족했던 움직임을 얼마나 보완했는지 하나의 대표 수치로 보여준다.

### 회복도 구성 예시

- 자세 전환 회복도
- 연속 좌식 회복도
- 식후 움직임 회복도
- 공간 이동 회복도
- 실외 활동 회복도

> 회복도는 의학적 건강 점수가 아니다.  
> 사용자의 평소 생활과 그날의 상황을 바탕으로 계산한 행동 지표이다.

## 기능 5. AI 주간 움직임 회복 리포트

### 리포트 예시

> 이번 주 평균 최장 연속 좌식 시간은 118분에서 76분으로 줄었습니다.  
> 특히 점심 식사 후 음악과 함께 제안한 짧은 움직임의 수행률이 82%로 가장 높았습니다.  
> 반면 오전 산책 제안은 대부분 미뤄졌습니다. 다음 주에는 오전 산책 대신 오후 4시의 짧은 실내 이동을 우선 제안하겠습니다.

### 포함 항목

- 지난주 대비 최장 연속 좌식 시간
- 자세 전환 횟수
- 결손 종류별 회복률
- 제안 수락률과 수행률
- 가장 효과적인 개입 시간
- 가장 효과적인 행동 종류
- 알림이 방해되었다고 평가한 시간
- 다음 주 개인화 목표

## 기능 6. 음성·텍스트 피드백

사용자는 ThinQ ON 또는 앱을 통해 짧게 의견을 남길 수 있다.

### 예시

- “지금은 회의 중이야.”
- “오늘은 너무 피곤해.”
- “산책보다는 스트레칭이 좋아.”
- “점심 이후에 알려줘.”
- “이 알림은 너무 자주 와.”

AI는 피드백을 다음 추천과 알림 빈도에 반영한다.

# 🔟 보상 체계

## 보상 설계의 목적

이 프로젝트는 좋은 행동을 추천하는 데서 끝나지 않고, 사용자가 실제로 행동하고 이를 꾸준히 유지하도록 만드는 것을 목표로 한다.

환경 변화나 음성 칭찬은 즉각적인 피드백으로 활용할 수 있지만, 장기적인 행동 유지에는 약할 수 있다. 따라서 핵심 보상은 **측정 가능한 회복도와 실질적인 가치가 있는 리워드**로 구성한다.

## 핵심 보상: 회복 크레딧

AI가 감지한 개인의 움직임 결손을 실제로 회복했을 때 지급하는 포인트이다.

| 결손 | 행동 예시 | 크레딧 예시 |
|---|---|---:|
| 연속 좌식 | 5분 걷기 | 10P |
| 식후 움직임 | 설거지·정리 | 10P |
| 자세 전환 | 스트레칭 | 5P |
| 실외 활동 | 15분 산책 | 20P |
| 일일 회복도 80% | 일일 보너스 | 20P |
| 주 5일 목표 달성 | 주간 보너스 | 100P |

### 설계 원칙

- 걸음 수나 운동량 자체에 무제한으로 지급하지 않는다.
- 사용자의 개인 기준과 결손 회복 여부를 중심으로 지급한다.
- AI 제안 없이 사용자가 자발적으로 움직인 경우도 인정한다.
- 하루 적립 상한을 둔다.
- 같은 행동의 반복 적립을 제한한다.
- 여러 결손을 균형 있게 회복하면 추가 보상을 제공한다.
- 하루 목표를 실패해도 기존 포인트를 차감하지 않는다.
- 강한 연속 출석보다 ‘최근 7일 중 5일’처럼 회복 가능한 목표를 사용한다.

# 1️⃣2️⃣ 전체 사용자 시나리오

## 시나리오 A. 재택근무자의 연속 좌식

1. 사용자가 오전 9시부터 책상에서 업무를 시작한다.
2. 위치와 자세 데이터에서 100분 이상 앉아 있는 상태가 감지된다.
3. 캘린더와 PC 사용 로그상 회의가 끝난 것을 확인한다.
4. AI가 “회의가 끝났어요. 물을 마시러 다녀오면서 3분 정도 움직여볼까요?”라고 제안한다.
5. 사용자가 책상에서 일어나 주방으로 이동한다.
6. 시스템이 위치·자세 변화를 감지해 수행을 확인한다.
7. 연속 좌식 결손 회복도가 상승하고 회복 크레딧이 지급된다.

## 시나리오 B. 취업 준비생의 식후 움직임

1. 주방가전 사용과 사용자의 이동을 통해 점심 식사 종료를 추정한다.
2. 사용자가 바로 책상에 앉아 40분 동안 움직이지 않는다.
3. AI가 “점심 이후 움직임이 없어요. 좋아하는 노래 한 곡 동안 방을 정리해보는 건 어떨까요?”라고 제안한다.
4. 사용자가 빨래를 정리하며 공간을 이동한다.
5. AI가 식후 움직임과 공간 이동 결손이 함께 회복되었다고 판단한다.
6. 앱에 회복도와 포인트가 반영된다.

## 시나리오 C. 하루 종일 외출하지 않은 사용자

1. 저녁 5시까지 현관 이동과 외부 GPS 데이터가 없다.
2. 날씨와 미세먼지가 산책에 적합하고 일정에도 여유가 있다.
3. 사용자는 오후 산책 제안의 수락률이 높다.
4. AI가 15분 산책을 제안한다.
5. 스마트폰 위치 변화로 실외 활동을 확인한다.
6. 실외 활동 결손 회복도와 주간 보너스 진행률이 올라간다.

## 시나리오 D. 제안을 거절하는 사용자

1. AI가 오전 11시에 스트레칭을 제안한다.
2. 사용자가 “지금 집중 중이야. 한 시간 뒤에 알려줘.”라고 말한다.
3. AI는 즉시 알림을 종료하고 해당 반응을 저장한다.
4. 이후 유사한 업무 패턴에서는 오전 11시를 피하고 점심 직전이나 업무 종료 직후를 선택한다.

# 1️⃣4️⃣ 대략적인 구현 방법

## MVP 구현 원칙

모든 센서와 가전을 실제 하드웨어로 구현할 필요는 없다. 핵심은 **다양한 생활 Context가 들어왔을 때 AI가 결손을 판단하고, 행동을 제안하며, 수행 결과까지 폐쇄 루프로 연결하는 과정**을 보여주는 것이다.

## 구현 범위 제안

### 반드시 구현

- 가상 센서 데이터 생성
- 사용자 위치·자세·체류시간 타임라인
- 움직임 결손 계산
- 상황별 행동 추천
- 수행 성공·실패 판단
- 앱 대시보드
- 회복도 및 주간 리포트
- 회복 크레딧과 리워드 스토어

### 선택적으로 실제 구현

- 웹캠 기반 자세 인식
- 스마트폰 GPS·가속도 연동
- PC 활동 로그
- 음성 피드백
- 일부 스마트 조명 또는 스피커 제어

## 가상 시뮬레이터

가상 주거 공간 안에서 사용자의 위치·자세와 센서 이벤트가 시간에 따라 변하는 모습을 보여준다.

### 표현 요소

- 책상·침대·소파·주방·현관 구역
- 사용자의 현재 위치
- 앉기·서기·눕기·이동 상태
- 각 공간 체류시간
- 움직임 결손 발생 표시
- AI 제안 전후 행동 변화
- 가전 및 앱 반응

### 구현 후보

- **Three.js:** 웹 기반 3D 시뮬레이터
- **Unity:** 시각적 완성도가 높은 시뮬레이터
- **React 기반 2D 디지털 트윈:** 구현 난도가 가장 낮음

한 학기와 4인 팀의 범위를 고려하면, 고품질 3D 그래픽보다 **React + Three.js 또는 2D 평면도 기반 시뮬레이터**가 현실적이다.

## 기술 스택 예시

| 영역 | 후보 기술 |
|---|---|
| 모바일 앱 | React Native 또는 Flutter |
| 웹 대시보드 | React + Vite |
| 가상 홈 | Three.js 또는 Unity |
| 백엔드 | FastAPI |
| 실시간 통신 | WebSocket 또는 MQTT |
| 데이터베이스 | Firebase 또는 PostgreSQL |
| 자세 인식 | MediaPipe Pose 또는 경량 YOLO Pose |
| 결손 분석 | 규칙 기반 기준선 + 시계열 특징 |
| 개인화 추천 | LightGBM, XGBoost, Contextual Bandit 후보 |
| 생성형 AI | 제안 이유·주간 리포트 생성 |
| 가전 시뮬레이션 | ThinQ 이벤트를 모사한 API |

## AI 구현 단계

### 1단계: 규칙 기반 기준선

초기에는 명확한 규칙으로 결손을 판정한다.

```text
연속 좌식 > 개인 기준
→ 연속 좌식 결손

식사 후 일정 시간 내 이동 없음
→ 식후 움직임 결손

하루 외부 이동 0분
→ 실외 활동 결손 후보
```

### 2단계: 개인화 추천 모델

다음 데이터를 학습해 어떤 제안을 선택할지 예측한다.

- 시간대
- 결손 유형
- 현재 행동
- 제안 종류
- 행동 소요 시간
- 이전 수락률
- 이전 수행률
- 피드백
- 보상 유형

### 예측 목표

> “현재 상황에서 어떤 행동과 보상을 제안했을 때 사용자가 실제로 수행할 확률이 가장 높은가?”

### 3단계: 생성형 AI 설명

판단 결과를 자연스러운 문장과 리포트로 변환한다. 생성형 AI는 결손 수치나 건강 기준을 임의로 만들지 않고, 분석 모델의 결과를 설명하는 역할로 제한한다.

# 1️⃣5️⃣ 기대효과와 검증 방법

## 직접 검증 가능한 효과

| 기대효과 | 측정 지표 |
|---|---|
| 장시간 연속 좌식 감소 | 최장 연속 좌식 시간 |
| 자세 전환 증가 | 일어서기·앉기 전환 횟수 |
| 가벼운 생활 움직임 증가 | 활동 중단 횟수, 공간 이동 |
| 제안 수행률 증가 | 제안 대비 실제 수행 비율 |
| 알림 피로 감소 | 무시·거절률, 방해 정도 설문 |
| 개인화 개선 | 사용 기간에 따른 수락률 변화 |
| 생활 인식 개선 | 결손 이해도와 만족도 설문 |
| 지속성 향상 | 주간 목표 달성일, 재사용 의향 |

## 보조적으로 측정할 효과

- 하루 종료 시 피로도
- 목·어깨·허리의 뻐근함
- 주관적인 활력
- 서비스 만족도
- 보상에 대한 동기 수준

## 직접 주장하지 않을 효과

- 질병 진단
- 만성질환 예방 효과 확정
- 자세 교정 치료
- 비타민 D 부족 판정
- 사용자에게 필요한 정확한 운동 처방
- 수명 연장

## 연구 근거

2023년 소규모 무작위 교차실험에서는 30분마다 5분씩 가볍게 걷는 조건이 계속 앉아 있는 조건보다 식후 혈당 반응과 혈압을 낮췄다. 다만 11명을 대상으로 한 단기 실험이므로 장기 질병 예방까지 단정해서는 안 된다.

- [Columbia University 연구 소개](https://www.cuimc.columbia.edu/news/rx-prolonged-sitting-five-minute-stroll-every-half-hour)

여러 단기 연구를 종합한 메타분석에서도 장시간 앉아 있는 시간을 서기 또는 가벼운 걷기로 중단했을 때 식후 혈당 관련 지표가 개선되었으며, 가벼운 걷기가 단순히 서 있는 것보다 상대적으로 뚜렷한 효과를 보였다.

- [좌식 중단과 가벼운 활동에 관한 체계적 문헌고찰 및 메타분석](https://pmc.ncbi.nlm.nih.gov/articles/PMC9325803/)

상황에 따라 적절한 시점에 건강 행동을 제안하는 JITAI 연구도 진행되어 왔다. 다만 센서 신뢰성과 개입 타이밍, 장기 지속성에 대한 연구는 아직 충분하지 않다. 이는 프로젝트의 약점인 동시에 **상황 인식형 개입이 고정 알림보다 실제 행동을 더 잘 유도하는지 검증할 연구 기회**가 된다.

- [신체활동 JITAI 체계적 문헌고찰](https://pmc.ncbi.nlm.nih.gov/articles/PMC6448257/)

## 핵심 연구 질문

> 고정된 시간에 보내는 일반 알림보다, 사용자의 자세·체류시간·생활 상황과 이전 반응을 고려한 AI 제안이 실제 움직임을 더 많이 유도하는가?

## 비교 실험 예시

### A 조건: 고정 알림

- 60분마다 동일한 알림
- 동일한 스트레칭 제안
- 상황과 이전 반응 미반영

### B 조건: Context 기반 AI

- 좌식 지속시간과 현재 상황 반영
- 행동 종류와 소요 시간 개인화
- 이전 수락·거절 반응 반영
- 회복 크레딧 제공

## 주요 비교 지표

- 최장 연속 좌식 시간
- 하루 활동 중단 횟수
- 알림 수락률
- 제안 수행률
- 알림 무시율
- 제안이 방해되었다는 응답
- 서비스 지속 사용 의향

## 보상 효과 추가 검증

가능하다면 다음 세 조건을 비교한다.

1. 제안만 제공

이를 통해 포인트가 단순 장식인지, 실제 행동 지속에 영향을 주는지 확인할 수 있다.

# 1️⃣7️⃣ 기존 시장 서비스와 중복 여부

## 유사 영역

Apple Watch는 움직이기·운동하기·일어서기를 링으로 표시하고, 한 시간 동안 일정 시간 서서 움직이는 목표와 활동 알림을 제공한다. Samsung Health도 장시간 비활동 상태일 때 활동이나 스트레칭을 안내할 수 있다.

- [Apple Watch 활동 추적 공식 안내](https://support.apple.com/guide/watch/track-daily-activity-apd3bf6d85a6/watchos)
- [Samsung Health 공식 지원](https://www.samsung.com/us/support/owners/app/samsung-health/)

따라서 다음 기능만으로는 차별성이 부족하다.

- 오래 앉아 있으면 알림
- 하루 걸음 수 표시
- 스트레칭 영상 추천
- 활동 링과 배지 제공
- 운동하면 포인트 지급

## 본 프로젝트의 차별점

| 기존 웨어러블·헬스 앱 | 본 프로젝트 |
|---|---|
| 신체에 착용한 센서 중심 | 집의 공간·가전·생활 Context 중심 |
| 걸음·칼로리·운동 시간 | 사라진 생활 움직임의 종류 |
| 비활동 시간 알림 | 개입 가능 시점과 행동 선택 |
| 정해진 활동 목표 | 개인별 움직임 결손 |
| 사용자가 운동을 시작 | 집이 생활 상황을 먼저 이해 |
| 알림 전달 중심 | 제안 → 수행 확인 → 회복도 → 보상 |
| 운동 기록 중심 | 집 안 생활 구조의 변화 중심 |

### 차별화 핵심

> 웨어러블이 사용자의 몸에서 활동량을 측정한다면, 이 서비스는 집이 사용자의 공간별 생활을 이해하고 어떤 움직임이 사라졌는지 판단한다.

# 1️⃣8️⃣ 역대 프로젝트와 중복 검토

## HARU와의 차이

- **HARU:** 건강·날씨·스트레스·위치 데이터를 바탕으로 사용자 니즈를 파악하고 가정환경을 구성
- **본 프로젝트:** 자세·체류·공간 행동을 분석하여 생활 움직임 결손을 찾고 실제 행동 및 보상으로 연결

환경 자동 조절을 핵심으로 하면 HARU와 겹칠 가능성이 크다. 따라서 조명·공조 제어는 보조 기능으로 두고, **행동 변화의 폐쇄 루프**를 중심에 둔다.

## 무드 매니저·퓨어케어와의 차이

- **기존:** 감정·스트레스·오디오·생체신호를 분석해 최적 환경 제공
- **본 프로젝트:** 환경을 편안하게 만드는 것이 아니라 사용자가 실제로 움직이도록 개입하고 수행을 확인

## HomeQuest와의 차이

포인트와 리워드를 사용하면 지난해 2등 팀인 HomeQuest와 외형적으로 유사해질 수 있으므로 차이를 명확히 해야 한다.

| HomeQuest | 본 프로젝트 |
|---|---|
| 가족 참여형 서비스 | 개인 생활 패턴 중심 |
| 가사·절약·헬스 챌린지 | 움직임 결손 회복 |
| 가족 랭킹과 경쟁 | 개인별 회복도 |
| 미션 수행과 게임화 | 센서 기반 결손 및 수행 검증 |
| 추천할 챌린지 예측 | 결손·개입 시점·보상 방식 학습 |
| 랜덤박스·마켓 | 웰니스·LG 생태계 보상 |

### 피해야 할 요소

- 가족 랭킹
- 다른 사용자와의 운동 경쟁
- 랜덤박스
- 일반적인 일일 챌린지 목록
- 가사·절약 등 너무 넓은 미션

### 반드시 강조할 요소

> 포인트는 챌린지 참여에 대한 보상이 아니라, AI가 발견한 개인의 움직임 결손이 실제로 회복되었음을 센서로 확인한 뒤 지급된다.

## LOCUS와의 차이

- **LOCUS:** 멀티모달 Context를 이해해 오염을 예측하고 선제적으로 청소
- **본 프로젝트:** Context를 이용한다는 점은 유사하지만, 예측 청소가 아니라 생활 속 움직임 공백을 판단하고 행동 변화를 유도

LOCUS처럼 기술을 많이 나열하기보다, 실제 사용자의 행동이 변하는 과정을 완결성 있게 보여주는 것이 중요하다.

# 1️⃣9️⃣ LG 관점에서의 가치

## ① ThinQ를 제어 앱에서 생활 플랫폼으로 확장

가전 ON/OFF와 사용 리포트를 넘어, 가전과 공간 데이터를 종합해 사용자의 생활 변화를 만드는 서비스로 확장할 수 있다.

## ② 다양한 가전을 하나의 목적 아래 연결

개별 가전의 기능을 강조하기보다 다음 데이터를 하나의 생활 Context로 사용한다.

- TV·모니터 사용
- 주방가전 사용
- 조명과 공조
- 스마트폰·웨어러블
- ThinQ ON 음성 인터페이스

## ③ 제품·구독·케어 서비스와 리워드 연결

회복 크레딧을 LG 소모품, 가전 관리, 구독료 할인과 연결하면 건강 행동 유도와 LG 생태계 체류를 동시에 만들 수 있다.

## ④ 웰니스 데이터 기반 신규 고객 경험

가전을 판매한 이후에도 사용자의 생활 패턴과 관계를 이어갈 수 있다. 다만 민감한 건강·생활 데이터이므로 명시적 동의와 최소 수집이 전제되어야 한다.

# 2️⃣2️⃣ 한 학기 MVP 권장 범위

## 핵심 MVP

> **연속 좌식·식후 움직임·공간 이동 결손을 분석하고, 개인화된 행동을 제안한 뒤 수행 여부를 확인하여 회복도와 크레딧에 반영한다.**

### 결손 유형

초기에는 다음 세 가지에 집중한다.

1. 연속 좌식 결손
2. 식후 움직임 결손
3. 공간 이동 결손

실외 활동과 자세 다양성은 확장 기능으로 둘 수 있다.

### 시연에 필요한 핵심 흐름

1. 가상 홈에서 장시간 책상 체류
2. 센서 데이터 누적
3. AI가 결손과 개입 가능 시점 판단
4. 앱 또는 ThinQ ON으로 행동 제안
5. 사용자가 이동
6. 수행 자동 확인
7. 회복도 증가
8. 회복 크레딧 지급
9. 주간 리포트와 리워드 스토어 반영

# 2️⃣6️⃣ 최종 요약

본 프로젝트는 집에 오래 머무는 사람에게 운동을 강요하는 서비스가 아니다. 외부 생활에서 자연스럽게 발생했지만 집에서는 사라진 자세 전환, 공간 이동, 식후 움직임과 같은 **생활 움직임 결손**을 발견하는 서비스이다.

AI는 사용자의 위치·자세·체류시간·생활 상황·이전 반응을 종합해 어떤 움직임이 부족한지 판단하고, 실제로 행동할 수 있는 순간에 가장 부담이 적은 방법을 제안한다. 이후 센서로 수행 여부를 확인해 움직임 결손 회복도에 반영하고, 꾸준한 행동을 회복 크레딧과 웰니스·LG 생태계 혜택으로 연결한다.

프로젝트의 가장 중요한 차별점은 다음과 같다.

> **운동을 추천하는 데서 끝나지 않고, 집이 생활 속 움직임의 공백을 발견하여 실제 행동·측정·보상까지 완성한다.**

최종적으로 만들고자 하는 것은 단순한 헬스 앱도, 정해진 시간에 울리는 비활동 알림도 아니다.

> **집 안에서 사라진 움직임을 이해하고, 사용자가 다시 움직일 수 있도록 돕는 AI 생활 파트너**
