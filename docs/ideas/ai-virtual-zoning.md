# 🏠 AI 기반 원룸 가상 공간 분리 서비스

> **한 칸의 집, 여러 개의 방**

ThinQ ON이 사용자의 생활 맥락을 이해하고 조명·음향·가전·디지털 환경을 구역별로 조율하여, 하나의 원룸 안에 집중·휴식 등 서로 구분되는 **가상 공간 경계**를 생성하는 AI 스마트홈 서비스

---

## 1️⃣ 프로젝트 배경

1인 가구가 생활하는 원룸에서는 책상, 침대, 주방이 하나의 공간에 밀집되어 있다. 업무·공부·휴식을 모두 같은 장소에서 수행하기 때문에 생활 간 경계가 흐려지고, 쉬는 동안에도 업무가 떠오르거나 집중해야 할 때 침대와 생활 소음의 영향을 받기 쉽다.

기존 스마트홈은 주로 큰 집과 가족 단위의 사용자를 대상으로 하거나, 방 전체의 조명·온도·음악을 상황에 맞게 바꾸는 **환경 자동화**에 집중한다.

그러나 원룸에 필요한 것은 단순히 쾌적한 환경이 아니라,

> **하나의 물리적 공간을 여러 개의 심리적·기능적 공간으로 구분해주는 것**이다.

---

## 2️⃣ 프로젝트 목적

### 🎯 최우선 목표

> **좁고 복잡한 원룸에서도 생활 간 경계를 느끼게 하여 사용자의 심리적 안정감을 높인다.**

휴식할 때는 업무 공간에서 벗어났다는 느낌을 주고, 공부할 때는 침대와 생활 공간으로부터 분리된 집중 공간에 들어왔다는 느낌을 제공한다.

집의 크기를 물리적으로 넓히는 것이 아니라, 사용자가 느끼는 **공간의 역할과 경계**를 확장하는 것이 핵심이다.

---

## 3️⃣ 핵심 기능

### ① 생활 Context 인식

ThinQ ON이 다음 데이터를 종합하여 사용자의 현재 생활과 전환 의도를 판단한다.

- 책상·침대 등 사용자의 위치
- 앉기, 눕기, 자리 이탈 등의 행동
- 노트북·TV·조명·가전 사용 상태
- 시간, 일정, 체류 시간
- 기존 환경 설정과 사용자 선호도
- 음성 및 수동 피드백

---

### ② 가상 공간 경계 생성

방 전체를 동일하게 바꾸는 것이 아니라, 생활 구역마다 서로 다른 환경을 조성한다.

| 집중 공간 | 휴식 공간 |
|----------|----------|
| 책상 주변 집중 조명 | 침대 주변 따뜻한 조명 |
| 음악·백색소음 또는 무음 | 편안한 음악과 미디어 환경 |
| 알림과 방해 요소 최소화 | 업무 관련 화면과 알림 차단 |
| 집중하기 적합한 온도·공기질 | 편안한 휴식 환경 조성 |

예를 들어 사용자가 책상에 앉아 업무를 시작하면 책상 주변은 밝고 선명하게, 침대 주변은 어둡게 조절한다. 이를 통해 실제 벽은 없지만 **"책상 구역 안으로 들어왔다"**는 감각을 만든다.

---

### ③ 생활 전환 지원

단순히 모드를 켜는 것이 아니라, 이전 생활을 마무리하고 다음 공간으로 이동하는 과정을 설계한다.

```
집중 종료 감지
→ 업무 화면과 알림 정리
→ 책상 조명 서서히 감소
→ 침대 주변 조명과 음향 활성화
→ 휴식 공간 경계 생성
```

이를 통해 사용자가 휴식 중에도 업무 상태를 계속 유지하는 문제를 줄이고, 생활 간 심리적 단절을 돕는다.

---

### ④ 개인화 공간 학습

AI는 사용자가 직접 입력한 설정뿐 아니라 실제 반응을 함께 학습한다.

- 조명·음악·온도를 다시 변경했는가?
- 공간 모드를 바로 종료했는가?
- 해당 모드를 얼마나 오래 유지했는가?
- 집중 중 자리 이탈이 줄었는가?
- 책상과 침대의 용도가 잘 구분되었는가?
- "음악이 거슬려", "지금은 편안해"와 같은 음성 피드백

예를 들어 사용자가 "밤에 공부할 때는 음악이 거슬려"라고 말하면 현재 음악을 끄고, 이후에는 야간 집중 공간을 무음으로 생성한다.

---

### ⑤ 판단 근거 설명

ThinQ ON은 공간을 전환한 이유를 자연어로 설명한다.

> "책상에서 노트북을 사용하고 있으며, 야간 집중 선호도를 반영해 책상 주변을 집중 공간으로 전환했습니다."

이를 통해 사용자는 AI의 판단을 이해하고 필요하면 즉시 수정할 수 있다.

---

## 4️⃣ 대표 시나리오

### 📚 집중 공간

사용자가 책상에 앉고 노트북을 실행한다.

ThinQ ON은 일정, 시간, 위치, 기기 사용 상태를 분석해 업무 시작을 판단한다. 책상 조명을 밝히고 침대 주변을 어둡게 하며, 사용자의 선호에 따라 음악을 재생한다. 스마트폰과 TV의 방해 요소도 줄인다.

### 🛏️ 휴식 공간

업무를 종료하고 침대로 이동한다.

책상 주변의 조명과 업무 화면이 비활성화되고, 침대 주변에 따뜻한 조명과 편안한 음향 환경이 형성된다. 같은 방 안에서도 사용자가 업무 공간에서 벗어났다고 느끼도록 한다.

---

## 5️⃣ 대략적인 구현 방법

실제 하드웨어 대신 **3D 가상 원룸 시뮬레이터**를 중심으로 구현한다.

- **3D 원룸:** React, Three.js 또는 React Three Fiber
- **사용자·센서 시뮬레이션:** 위치, 자세, 시간, 가전 상태를 가상 데이터로 생성
- **AI 판단 서버:** FastAPI 기반 Context 분석 및 공간 모드 결정
- **개인화 모델:** 사용자 설정 변경과 피드백을 바탕으로 선호 학습
- **음성 피드백:** STT와 LLM을 활용해 제어 요청과 선호도 피드백 구분
- **IoT 통신:** MQTT 및 WebSocket으로 가상 가전과 3D 공간을 실시간 변경
- **ThinQ ON:** 센서·AI·LG 가전을 연결하는 가상 AI 홈 허브로 구현

시뮬레이터에서는 사용자가 책상과 침대 사이를 이동할 때 조명, 음향, 온도, 가전 상태와 가상 경계가 어떻게 변하는지 시각적으로 보여준다.

---

## 6️⃣ 기대효과

### 🧠 심리적 안정감

휴식 공간에서 업무 요소를 약화하여 사용자가 "이제 쉬어도 된다"는 명확한 전환을 느끼도록 한다.

### 🚪 생활 간 경계 형성

공간적 제약으로 섞여 있던 공부·업무·휴식을 구분하여 각 생활의 시작과 종료를 명확하게 만든다.

### 🎯 집중력 향상

책상 주변의 자극은 집중에 맞게 조율하고 침대·TV 등 방해 요소는 약화하여 집중 환경을 형성한다.

### 🏠 원룸의 공간 가치 확장

가구나 벽을 추가하지 않고 기존 가전과 환경 요소를 활용해 하나의 방이 여러 역할을 수행하도록 한다.

### 🤖 개인화된 장기 적응

AI가 사용자의 반응을 학습하면서 모든 사람에게 동일한 환경이 아닌, 개인이 실제로 공간 분리를 느끼는 환경을 찾아간다.

---

## 7️⃣ 기존 시장과의 중복 여부

| 기존 시장 접근 | 본 프로젝트의 차이 |
|---|---|
| 상황별 스마트홈 루틴 | 방 전체 제어가 아닌 구역별 공간 경계 생성 |
| Philips Hue 집중·휴식 조명 | 조명뿐 아니라 음향·가전·디지털 환경 통합 |
| SmartThings 행동·위치 기반 자동화 | 환경 편의보다 생활 간 심리적 분리를 목표로 함 |
| Ori 로봇 가구 | 물리적 공간 변형 없이 가상·감각적 공간 분리 |
| LG ThinQ 개인화 루틴 | ThinQ ON을 가전 제어기가 아닌 공간 조율 AI로 확장 |

조명·음악·온도를 개인화하는 기능 자체는 이미 시장에 존재한다. 따라서 본 프로젝트는 **"개인화된 환경 조성"이 아니라 "하나의 방에 여러 공간의 경계를 생성한다"**는 점을 일관되게 유지해야 한다.

---

## 📌 프로젝트 핵심

> 우리는 사용자에게 가장 쾌적한 하나의 방을 만드는 것이 아니다.
> **하나의 원룸 안에서 공부할 때는 집중 공간에, 휴식할 때는 편안한 공간에 있다고 느끼게 만드는 AI를 구현한다.**
